# NEXUS Browser for Windows

NEXUS Browser is a Chromium-based desktop browser with a modern light UI, tabs, address/search bar, bookmarks, history and downloads.

## Download

Open the [Releases](https://github.com/wpguidexpro-hub/NEXUS-Browser-Releases/releases/latest) page and download **NEXUS-Browser-Setup-1.1.0-x64.exe**.

The installer bundles the NEXUS Search backend and starts it automatically on `127.0.0.1:9200` when needed. Search results are rendered in a single NEXUS page; live sources can include Bing and DuckDuckGo, while providers that block automated requests may be skipped.

**Windows notice:** This build is not code-signed, so Windows SmartScreen may show an unknown publisher warning.
