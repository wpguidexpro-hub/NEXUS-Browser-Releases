# NEXUS Browser — Windows and Android

NEXUS Browser includes a Chromium-based Windows browser and a native Android browser for phones and tablets. Both use the shared NEXUS Search service.

## Downloads
- Windows: download the current installer from the [NEXUS Browser Releases](https://github.com/wpguidexpro-hub/NEXUS-Browser-Releases/releases/latest) page.
- Android: download [NEXUS Mobile 1.4.0 APK](https://wpguidexpro-hub.github.io/NEXUS-Browser-Releases/NEXUS-Mobile-v1.4.0.apk).
- Android update feed: [update.json](https://wpguidexpro-hub.github.io/NEXUS-Browser-Releases/update.json).

## Android v1.4.0
- Chrome-style top toolbar; no app-level bottom action bar.
- NEXUS-only home shortcuts; no Google or YouTube shortcut buttons.
- About NEXUS links to the GitHub repository and official website.
- Update manifest records versionCode 17 and the SHA-256 checksum.

## Windows
The Windows app includes tabs, an address/search bar, bookmarks, history and downloads. The browser is not code-signed, so Windows SmartScreen may show an unknown-publisher warning.

Search results depend on the shared NEXUS Search service and its configured providers, which can sometimes be unavailable or rate-limit requests.
